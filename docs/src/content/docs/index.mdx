## Architecture as typed Python

A `.scry` file is executable Python with a focused, Pydantic-backed vocabulary. Describe components, connections, owners, frameworks, deployments, docs, and evidence without inventing another brittle diagram format.

```python title="index.scry"
from scryr import Diagram, Github, Info, Manifest
from scryr.types import ProgrammingLanguage, WebFramework

api = Manifest(
    manifest_id="services/api",
    name="Public API",
    icon="⚡",
    connections=[Manifest(name="Postgres")],
    info=Info(
        description="Customer-facing FastAPI service",
        language=ProgrammingLanguage.python,
        frameworks=[WebFramework.fastapi],
        owner_team="Platform",
    ),
    github=Github(repo_url="https://github.com/acme/api"),
)

database = Manifest(name="Postgres", icon="◇")
system = Diagram(name="Production", manifests=[api, database])
```

## The first ritual

1. Install Scryr: `brew install scryr-app/tap/scryr`
2. Create or generate `index.scry` in your repository.
3. Run `scryr serve --watch` and explore.

:::caution
A `.scry` manifest is Python. Only run manifests you trust, and review agent-written code before executing it.
:::
