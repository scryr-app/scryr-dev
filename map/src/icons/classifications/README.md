# Classification icons

All architectural symbols use IBM Carbon (Apache 2.0), except gRPC and the two
GraphQL classifications, which use SVG Logos (CC0). Assets are bundled locally.

Source: [Iconify icon sets](https://github.com/iconify/icon-sets/tree/master/json), retrieved 2026-10-19.
Carbon: IBM and contributors. SVG Logos: Gil Barbara and contributors.
The upstream license texts are included in this directory.
