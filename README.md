# 🔮 Scryr

Actionable architecture.

## Workspace

This repo has three main projects:

- `map`: React/Three.js frontend
- `crystal`: Rust GraphQL server
- `manifest`: Python manifest tooling

## Get Started

After you install scryr, execute:

```bash
scryr serve
scryr generate upload
```
